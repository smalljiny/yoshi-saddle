## STATUS_CURRENT

```text
현재 주제: {topic}
단계: {phase}
```

## ACTIVE_TITLE

```text
Active 토픽:
```

## ACTIVE_CURRENT_LINE

```text
  * {topic} (현재) — {phase}
```

## ACTIVE_OTHER_LINE

```text
    {topic} — {phase}
```

## BACKLOG_TITLE

```text
Backlog 토픽:
```

## BACKLOG_LINE

```text
  - {topic}
```

## NO_ACTIVE

```text
진행 중인 주제가 없습니다.
새 주제를 시작하려면: /flow-spec <topic>
백로그에서 구현을 시작하려면: /flow-plan <topic>
```

## BACKLOG_TOPIC_HINT

```text
'{name}'은 backlog 토픽입니다.
플래닝을 시작하려면: /flow-plan {name}
```

## TOPIC_NOT_FOUND

```text
'{name}' 토픽을 찾을 수 없습니다.
스펙을 작성하려면: /flow-spec {name}
```

## SWITCHED

```text
현재 주제가 '{name}'으로 전환되었습니다.
단계: {phase}
```

## DEPRECATED

```text
⚠ /flow-topic {name}으로 주제를 등록하는 방식은 더 이상 사용하지 않습니다.
스펙 작성과 주제 등록을 함께 시작하려면:
  /flow-spec {name}
```
